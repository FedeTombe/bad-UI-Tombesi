# bad-UI-Tombesi
IISAIA
Este proyecto es una interfaz intencionalmente frustrante inspirada en el concepto de "bad UI". La página deriva simplemente a un botón de aceptar, el cuál presenta una sucesión de ridiculeces para confirmar que el usuario EVIDENTEMENTE quiere aceptar la orden (sea cual sea).

Todo el proyecto está construido en un único archivo `index.html`, sin frameworks ni dependencias externas.

## Objetivo

Explorar malas prácticas de experiencia de usuario de forma humorística e interactiva.
